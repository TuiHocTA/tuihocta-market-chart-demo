# TuiHocTA Market Chart

TuiHocTA is a public Vietnam market analytics platform focused on data-driven technical analysis.

Current data modules include:

- VNINDEX OHLCV history
- Market Breadth
- Advance / Decline
- A/D Line
- New High / New Low
- Volume-based market internals
- Relative Strength
- Sector and Industry Strength

Website: https://tuihocta.com

This repository is a public project profile for the TuiHocTA charting integration.
